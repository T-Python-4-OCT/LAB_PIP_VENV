# LAB_PIP_VENV

## using what you've learned , create a new project to print Text Art in the terminal :
- Create a virtual environment & activate it
- Install & Use the Faker package, write a program that:
1. Asks the user how many profiles they want to generate.
2. Generates the requested number of fake profiles.
3. Each profile must include:
   - Full name
   - Email address
   - Phone number
   - City
4. Displays each profile in a readable format.

Expected Output
```
How many profiles? 2

--- User 1 ---
Name: John Smith
Email: john.smith@example.com
Phone: 555-123-4567
City: New York

--- User 2 ---
Name: Sarah Johnson
Email: sarah@example.com
Phone: 555-987-6543
City: Chicago

```

5. Generate a requirements.txt file using pip (use pip freeze)
